!!! tip "[PEC anévrysme artère splénique](https://radiopaedia.org/articles/splenic-artery-aneurysm){:target="_blank"}"
    - chirurgie si **≥ 3 cm** avec majoration / risque de **grossesse** 
    - surveillance annuelle sinon

!!! tip "[calcifications spléniques](https://radiopaedia.org/articles/splenic-calcification){:target="_blank"}"
    - corps de Gamna Gandy = hypertension portale +++, drépanocytose, anémie hémolytique    
    - granulomes calcifiés = pneumocystose +++, sarcoïdose, tuberculose
    - cicatricielles = anciens micro-abcès, cysticercose
